================================================================================
                 Match Record Tool — 比赛数据记录工具
                            使用说明 (README)
================================================================================

【简介】
Match Record Tool 是一个纯前端网页应用，用于在比赛进行中实时记录比分、球员数据、
事件时间线等。支持篮球、足球以及自定义运动类型。所有数据保存在浏览器的
LocalStorage 中，无需安装任何软件，双击 index.html 即可使用。

================================================================================
【一、快速开始】
================================================================================

1. 用浏览器打开 index.html 文件（推荐 Chrome / Edge / Firefox 最新版）。
2. 首页默认为"比赛列表"页面（比赛为空）。
3. 建议操作顺序：
   (1) 先进入"队伍管理"页面，创建主队和客队，并为每队添加球员。
   (2) 返回首页，点击"+ 新建比赛"创建一场比赛。
   (3) 点击比赛卡片进入比赛记录页面，开始实时记录。

================================================================================
【二、页面导航】
================================================================================

应用包含 4 个主要页面，通过顶部导航栏切换：

  1. 首页（比赛列表） — 查看所有比赛、筛选运动类型、新建/编辑/删除比赛
  2. 队伍管理          — 创建和编辑队伍、添加/编辑/删除球员
  3. 比赛记录          — 实时记录比赛的核心页面（计分、计时、事件）
  4. 数据统计          — 查看已完成比赛的数据统计和图表

================================================================================
【三、队伍管理】
================================================================================

1. 点击"+ 新建队伍"，输入队伍名称并选择代表颜色。
2. 队伍创建后，点击"+ 添加球员"，填写：
   - 姓名：球员姓名
   - 号码：球衣号码（数字）
   - 位置：如篮球的 PG/SG/SF/PF/C，足球的 GK/DF/MF/FW（可自由填写）
3. 可以随时编辑队伍信息或删除球员。

================================================================================
【四、创建比赛】
================================================================================

1. 在首页点击"+ 新建比赛"。
2. 填写以下信息：
   - 比赛名称：如"决赛"、"小组赛 A 组"
   - 运动类型：篮球 / 足球 / 自定义
   - 主队 & 客队：从已创建的队伍中选择

3. 比赛规则设置（可展开）：
   - 节数/半场数：篮球默认 4 节，足球默认 2 半场
   - 每节时长：分钟数
   - 获胜条件：
     ○ 时间结束时分高者胜（常规规则）
     ○ 率先得到 N 分获胜（先到 N 分制，如街头篮球 21 分制）
   - 加时赛：可启用/禁用，设置加时赛时长

4. 自定义运动类型：
   - 选择"自定义"后，可填写运动名称（如"排球"、"网球"）
   - 在"自定义比赛数据项"中添加需要记录的数据字段（如扣球、拦网、发球得分等）
   - 比赛记录页会自动生成对应的 +/- 按钮和快速事件

================================================================================
【五、比赛记录页面（核心功能）】
================================================================================

进入一场比赛后，你将看到以下区域：

┌──────────────────────┐  ┌──────────────────────────┐
│  计分板（比分 + 加减） │  │  篮球：球员面板（数据统计）│
│  计时器（开始/暂停）   │  │  足球：球员上场管理       │
│  快速事件按钮         │  │                          │
│  篮球/足球球队数据面板 │  │  事件时间线              │
└──────────────────────┘  └──────────────────────────┘

【5.1 计分板】
  - 篮球：点击 +1（罚球）、+2（投篮）、+3（三分）为主客队加分
  - 足球：通过快速事件"进球"按钮选择进球球员和助攻球员
  - 自定义：通过快速事件按钮记录事件并累加对应数据
  - 撤销按钮：撤销最后一次得分

【5.2 计时器】
  - 点击"开始"启动计时器
  - 篮球为倒计时（从 10 分钟开始减少），足球为正计时（从 0 开始累计）
  - 当倒计时归零时自动弹窗提示当前节次结束

【5.3 快速事件按钮】
  - 篮球：犯规、暂停、换人、失误
  - 足球：进球（含球员选择器+助攻选择器）、黄牌、红牌（含球员选择器）
    * 累计 2 张黄牌自动变为红牌，球员被罚下
    * 红牌球员自动从场上移除
  - 足球的犯规、角球、越位在球队数据面板中记录

【5.4 球员面板（篮球）】
  - 点击球员可展开其数据统计面板
  - 记录：得分(PTS)、投篮命中/出手、三分命中/出手、罚球命中/出手、
          进攻/防守篮板、助攻、盖帽、抢断、犯规、失误
  - 每个数据项有 + 和 - 按钮微调
  - "在场球员"动态管理（可替换上场/下场球员）

【5.5 球队数据面板（足球）】
  - 控球率追踪：点击主/客队按钮标记控球方，每 30 秒自动更新百分比
  - 射门、射正、传球、传球成功、拦截、封堵射门
  - 角球、越位、犯规、黄牌、红牌（均有 +/- 按钮）
  - 犯规/角球/越位在此面板中记录

【5.6 自定义数据面板】
  - 显示在创建比赛时定义的自定义字段
  - 每项数据有主客队两组的 +/- 按钮

【5.7 事件时间线】
  - 记录所有比赛事件的详细时间线
  - 显示事件类型、时间、所属队伍、球员、描述
  - 支持按类型筛选（得分、犯规、换人等）
  - 支持删除单个事件
  - 自动记录节/半场开始和结束事件

【5.8 节次管理】
  - 点击"下一节"进入下一节次，计时器重置
  - 常规时间结束后如有平局，可选择进入加时赛
  - 点击"结束比赛"完成比赛（结束后数据不可再修改）

================================================================================
【六、数据导入导出】
================================================================================

【6.1 JSON 导出/导入】
  - 比赛记录页 → 点击"📤 JSON"导出单场比赛为 JSON 文件
  - 可用于数据备份或迁移到其他浏览器
  - 通过文件选择器导入 JSON（支持合并或覆盖模式）

【6.2 Excel 导出】
  - 比赛记录页 → 点击"📥 Excel"导出单场比赛为 .xlsx 文件
  - 包含 3 个工作表：
    (1) 比赛概览：名称、比分、日期等基本信息
    (2) 球员统计（篮球）/ 球队统计（足球）/ 比赛数据（自定义）
    (3) 事件时间线：所有事件的详细记录
  - 依赖 SheetJS 库（已通过 CDN 引入，需网络连接）

================================================================================
【七、数据存储说明】
================================================================================

- 所有数据存储在浏览器的 LocalStorage 中
- 数据不会上传到任何服务器，完全本地化
- 清除浏览器数据会导致比赛记录丢失，建议定期导出备份
- 支持 JSON 格式的完整数据备份与恢复

================================================================================
【八、支持的浏览器及技术说明】
================================================================================

- 推荐使用：Chrome 90+ / Edge 90+ / Firefox 90+ / Safari 14+
- 需要启用 JavaScript
- Excel 导出功能需要网络连接（CDN 加载 SheetJS 库）
- 其他功能可完全离线使用
